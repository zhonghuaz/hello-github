# 💰 牛马计费器 - 实时赚钱计数器微信小程序

一款通过「实时赚钱数值 + 强反馈动画音效」让用户直观感受到 **时间 = 金钱** 的微信小程序。

## 🚀 部署步骤

### 前置条件

1. **微信开发者工具**：前往 [微信开发者工具下载页面](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装最新版本
2. **微信小程序账号**（可选）：
   - 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序账号
   - 在「开发管理」→「开发设置」中获取 AppID
   - **如果只是本地预览/测试，可以使用测试号（无需注册）**

### 步骤一：导入项目

1. 打开 **微信开发者工具**
2. 点击左侧「**+**」号或「**导入项目**」
3. 选择项目目录：选择 `牛马计费器` 文件夹
4. AppID 设置：
   - 如果有小程序账号：填入你的 AppID
   - 如果没有：选择「**测试号**」（使用体验版功能）
5. 点击「**确定**」导入

### 步骤二：本地预览与调试

1. 导入成功后，开发者工具会自动编译并在左侧模拟器中显示小程序
2. 在模拟器中即可进行功能测试：
   - 输入月薪金额
   - 选择上下班时间
   - 点击「开始赚钱」按钮
3. 使用右侧「**调试器**」面板查看 Console 日志和网络请求

### 步骤三：真机预览

1. 在开发者工具顶部点击「**预览**」按钮
2. 使用微信扫描生成的二维码
3. 即可在手机上体验小程序

### 步骤四：上传发布（需要正式 AppID）

1. 确保 `project.config.json` 中的 `appid` 已替换为你的正式 AppID：
   ```json
   {
     "appid": "你的AppID"
   }
   ```
2. 在开发者工具顶部点击「**上传**」按钮
3. 填写版本号和项目备注
4. 登录 [微信公众平台](https://mp.weixin.qq.com/)
5. 进入「管理」→「版本管理」
6. 在「开发版本」中找到刚上传的版本
7. 点击「**提交审核**」
8. 审核通过后点击「**全量发布**」

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 💵 月薪输入 | 支持数字键盘输入月薪金额 |
| 🕐 时间选择 | picker 组件选择上下班时间 |
| ⏱ 实时计算 | 每秒更新已赚金额，精确到分 |
| 🪙 金币动画 | 每赚满 10 元整数倍触发 Canvas 金币掉落动画 |
| 🔊 音效反馈 | 金币掉落时播放金属音效 |
| ⏸ 暂停/继续 | 支持暂停和继续计时 |
| 📱 前后台切换 | 后台暂停，前台自动补算金额 |
| 🕐 工作时间检查 | 非工作时间自动提示 |

## 🔧 配置说明

### 修改默认月工作天数

在 [`app.js`](app.js:5) 中修改：

```javascript
globalData: {
  workDaysPerMonth: 21.75  // 修改此值
}
```

### 音效文件替换

将你的音效文件放入 `assets/` 目录，支持格式：`.mp3`、`.wav`、`.aac`

在 [`index.js`](pages/index/index.js:79) 中修改音频路径：

```javascript
this._audioContext.src = '/assets/your-sound-file.wav';
```

## 📐 计算公式

```
每秒收入 = 月薪 ÷ 月工作天数(21.75) ÷ 每日工作秒数

每日工作秒数 = (下班时间 - 上班时间) × 3600

示例：月薪 10000 元，9:00-18:00
每秒收入 = 10000 ÷ 21.75 ÷ (9 × 3600) ≈ 0.0142 元/秒
```

## ⚠️ 注意事项

1. **音效文件大小**：微信小程序包体积限制为 2MB（分包 20MB），请确保音效文件不要过大
2. **Canvas 性能**：金币动画使用 Canvas 2D 实现，在低端设备上可能有性能差异
3. **后台限制**：微信小程序进入后台后 JS 执行会被暂停，本项目已处理前后台切换的金额补算
4. **时间精度**：使用 `setInterval` 1秒间隔 + `Date.now()` 差值计算，确保累计金额准确
